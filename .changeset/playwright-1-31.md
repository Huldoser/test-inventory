Support Playwright 1.31 and newer, from 1.42: about 3.7 million weekly downloads of `@playwright/test` are on 1.31 to 1.41, and projects on them got an `unsupported-framework-version` warning. Before 1.42 the scan follows what those versions do, read from their source and checked by running them: a describe with details throws, so the file fails to load (`invalid-chain`); a test with details is listed without their tags and fails when it runs (an `invalid-chain` warning); `test.fail(title, body)`, and `test.skip()`, `fixme()` or `fail()` with details, declare no test and apply to every test in the scope (`skip-without-body`); a test without a body loads and fails when it runs (a `test-without-body` warning); and a test has only the tags of its own title, as Playwright's report gives them. Comparing the fixtures with Playwright 1.31.2, 1.34.3, 1.38.1 and 1.41.2 found no difference beyond the files that fail to load, and none on a copy whose describes have no details, except the state a describe's `test.fail()` sets, which `--list` shows only from 1.38 and a run applies in each. Playwright 1.30 and older keep the tests of a file that fails to load, so they stay unsupported.
